Local-First Vector ETL & Document Chunking Engine

Public Repository · Open Source

01. Purpose

Provides engineers with a zero-telemetry, memory-efficient pipeline for parsing complex PDFs, markdown files, and data tables into semantically coherent embedding chunks.

Streaming file parser with heuristic table recognition, content deduplication via MinHash, and pluggable connector support for Qdrant, Milvus, and ChromaDB.

03. Performance

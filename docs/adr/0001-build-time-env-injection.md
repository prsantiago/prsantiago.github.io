# Build-time `.env` injection from `src/` to `dist/`

Personal identity fields (`OWNER_NAME`, `BRAND_NAME`, `LINKEDIN_USERNAME`, `GH_USERNAME`) are stored in a gitignored `.env` file locally (copied from `.env.example`) and in GitHub Actions Variables in CI. Rather than fetching a config file in the browser or overwriting tracked root HTML files in-place, `scripts/build.js` renders HTML templates from `src/` into a gitignored `dist/` directory during `npm run build`, and `.github/workflows/deploy.yml` publishes `dist/`. This keeps `.env` out of Git and off the public server, preserves placeholders across repeated builds, and ensures static `<meta>` tags and links work with zero runtime JavaScript.
